# Elementor 组件

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Basic" />

Elementor 包含众多开发者可以修改的组件，以扩展 Elementor 的功能。本节列出了当前文档所涵盖的组件。

## 可用组件

以下是 Elementor 组件的列表，附有简短说明和更深入信息的链接：

*   [小部件](src/widgets)

    Elementor 在小部件面板中包含数十个有用的小部件。开发者可以创建自己的小部件，引入 Elementor 目前不具备的高级功能。

*   [控件](src/controls)

    Elementor 控件是用于构建界面的输入字段和 UI 元素。开发者可以自定义可用设置，并更改编辑器预览区域中的设计。

*   [动态标签](src/dynamic-tags)

    动态标签用于根据各种来源插入自定义数据。插件开发者可以创建广泛的动态标签，甚至可以使用外部 API 将数据拉取到 Elementor。

*   [表单操作](src/form-actions)

    表单操作是访问者提交表单数据后执行的任务。一个操作可以通过电子邮件发送表单数据、重定向到不同页面或将数据发送到外部服务。

*   [表单字段](src/form-fields)

    表单字段帮助用户使用 Elementor 表单小部件创建网页表单。插件开发者可以扩展数十种内置字段类型以添加新的字段类型。

*   [主题条件](src/theme-conditions)

    主题构建器使用基于条件的机制来显示模板。该机制涵盖了原生的 WordPress 模板层次结构，但开发者可以添加额外的条件。

*   [主题位置](src/themes)

    主题构建器将 Elementor 从页面构建器转变为完整的站点构建器。主题开发者可以通过主题位置使其主题“与 Elementor 兼容”。

*   [上下文菜单](src/context-menu)

    在预览区域编辑元素时，右键单击元素可以访问可通过上下文菜单应用的操作。可以向这些上下文菜单添加自定义操作。

*   [查找器](src/finder)

    查找器可以轻松访问站点上的许多页面和设置。开发者可以扩展查找器，添加和删除项目及类别。

## 更多组件

随着 Elementor 的发展，我们将为更多组件添加文档。这是我们鼓励和支持第三方开发者的基本承诺的一部分。作为此过程的一部分，我们正在尽一切可能简化我们的代码库，使外部开发者更容易在 Elementor 基础设施中实现他们的想法。
