# 要求

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Basic" />

在开始工作之前，请确保您满足以下概述的要求。

## 服务器

要开始工作，您需要一个 WordPress 站点，最好是一个全新的 WordPress 安装（本地主机或暂存/开发环境）。您可以使用运行 WordPress 所需的基本[服务器要求](https://wordpress.org/about/requirements/)。

您的服务器应使用满足或超过 [Elementor 要求](https://wordpress.org/plugins/elementor/#installation) 的 PHP 版本。

## 插件和主题

您的站点应安装 [Elementor 插件](https://wordpress.org/plugins/elementor/) 和 [Hello 主题](https://wordpress.org/themes/hello-elementor/)。如果您计划为 Elementor Pro 开发插件，则需要安装 [Elementor Pro](https://elementor.com/pro/)。

## 编程语言

我们还建议您具备 [WordPress 插件开发](https://developer.wordpress.org/plugins/) 的实用知识，并熟悉 HTML、CSS、JavaScript 和 PHP。
