# 文档网站

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Basic" />

为了进一步支持和鼓励开发者社区，Elementor 创建了这个更新和修订后的文档中心，开发者可以在此访问详细的文档，清晰地了解 Elementor 的工作原理以及它为开发者提供的选项。

## 使用本文档

本网站包含的文档描述了 Elementor 的概念和组件、它们的工作原理以及如何修改它们。通过这些信息，您应该能够在短时间内创建自己的插件。

## 文档结构

顶部导航栏分为三个主要区域：

* [入门指南](src/getting-started)
* [Elementor 内部原理](src/getting-started/internals)
* [Elementor 组件](src/getting-started/components)

在描述 Elementor 组件的章节中，您经常会找到指导您如何创建自己插件的教程，逐步引导您完成每个步骤。您可以随意复制此代码，并根据您的需求进行修改。

## 通过代码示例学习

在每个主题的末尾，您会找到完整插件的代码示例，展示如何运用您在该主题中学到的知识来创建自己的插件。然后，您可以获取这些插件并将其复制到您自己的项目中使用，或作为创建原创插件的起点。

## 为文档做贡献

此文档平台使用基于 Markdown 页面（`*.md` 文件）构建的静态站点生成器。如果您发现错误或希望贡献和改进文档，请使用位于每个页面底部的“**在 Github 上编辑此页面**”链接。

当然，我们无法承诺实施您的所有建议。评论在添加到文档之前将经过审核流程。
