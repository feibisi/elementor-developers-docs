# 什么是 Elementor？

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Basic" />

Elementor 是终极的 WordPress 网站构建器，它让用户能够直观、专业地创建像素级完美的 WordPress 网站，而无需编写代码。同时，它提供了一个框架，允许开发者扩展其功能，为用户提供更多特性。Elementor 不仅使用起来极其简便，而且功能强大、灵活，让创作者能够在 Elementor 框架内实现复杂的设计和功能。

## Elementor 版本

Elementor 提供不同版本：

**Elementor Core** 是一个免费的 WordPress 插件。它包含 Elementor 的核心功能，让用户能够通过具备拖放功能的图形用户界面来构建网站。

**Elementor Pro** 是一个付费版本，增加了许多免费版所不具备的高级功能和选项。它极大地丰富并改进了专业网页创作者可用的工具。

**Elementor Beta Developer** 是 Elementor Pro 插件的一个版本，面向开发者提供，让他们能够预览我们尚在开发中的最先进功能。该版本几乎每日更新，使开发者能在新功能公开发布前有时间熟悉它们。

除了这些版本，外部开发者还致力于创建 **Elementor 扩展插件**，为 Elementor 引入他们自己的功能，其中许多已被我们的用户广泛采用。

## Elementor 的发展

目前已有超过 1300 万个活跃网站由 Elementor 驱动，对新解决方案的需求持续增长。网站创作者始终在寻找 Elementor 功能集范围之外的新颖、细分功能。

## Elementor 生态圈

多年来，为满足这一需求，外部开发者已为 Elementor 创建了数百款自定义插件。这些插件随后被[推广和销售](https://elementor.com/addons/)给数百万 Elementor 用户，构成了不断壮大的 Elementor 生态圈。我们的文档旨在帮助您加入这个蓬勃发展的市场。

## Elementor 社区

五年来，Elementor 始终自豪地为网站创作者提供最优质的页面与站点构建软件。

与此同时，Elementor 社区也激励着全球的外部开发者创建强大的扩展、精致的部件、将先进的 JavaScript 库与 Elementor 集成，并定制主题。所有这些都助力拓宽了 Elementor 的能力边界。

Elementor 的基础架构能够支持许多产品本身未包含的特性和功能。这种灵活性帮助 Elementor 成为最受欢迎的 WordPress 插件之一。您有机会加入这个快速发展的开发者与网站创作者社区，交流建议，并成长为一名专业的附加组件开发者。
