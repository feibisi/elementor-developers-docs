# Elementor 编辑器控件

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Advanced" />

Elementor 编辑器控件是用于构建界面的**输入字段**和**UI 元素**。控件允许用户自定义可用面板设置，并在预览中更改设计。

Elementor 开箱即用，提供了广泛的控件。它们被用于小部件和编辑器面板中，以收集用户数据并根据用户选择生成自定义输出。
