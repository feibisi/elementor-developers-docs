# Elementor 控件

<Badge type="tip" vertical="top" text="Elementor Core" /> <Badge type="warning" vertical="top" text="Advanced" />

Elementor 控件是用于构建界面的**输入字段**和**UI 元素**。控件允许用户自定义可用面板设置，并在预览中更改设计。

Elementor 包含一系列开箱即用的控件。它们被用于小部件和面板中，以收集访问者数据并根据其选择生成自定义输出。
